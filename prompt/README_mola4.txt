МАРС В РАЗРЕЗЕ. СЕТКА MOLA ДЛЯ ЗАЛИВКИ

Файл mola4_topography_m.csv — вся поверхность Марса, 4 пикселя на градус.
Это перевод исходного файла NASA/PDS megt90n000cb.img в обычную таблицу
без изменения значений, интерполяции, округления или сглаживания.

Открытие
Импортируйте CSV с разделителем «запятая», без строки заголовков.
В файле 720 строк и 1440 столбцов. Каждое число — высота в метрах.
Первое число является данными, а не заголовком. Кодировка UTF-8.
Для обработки в браузере можно прочитать файл целиком и разделить
текст по строкам, а каждую строку — по запятым.

Что измерено
Высота отсчитывается от ареоида: это поверхность отсчёта высот Марса.
Отрицательная высота означает поверхность ниже ареоида, а не «нет данных».
В этом продукте нет пустых ячеек: где наблюдений MOLA не было, авторы
карты интерполировали значения. Ноль — допустимая высота, не пропуск.
Каждая ячейка содержит медиану высот в участке 0,25° × 0,25°.
Это данные о современном рельефе, а не реконструкция древнего берега.

Где находятся ячейки
Строки идут с севера на юг, столбцы — с запада на восток.
Используется планетоцентрическая широта и восточная долгота от 0° до 360°.
Центр первой ячейки: 89,875° с. ш., 0,125° в. д.
Центр последней: 89,875° ю. ш., 359,875° в. д.

Если номера строки L и столбца C начинаются с 1, как в таблице:
  широта центра = 90 − (L − 0,5) / 4;
  восточная долгота центра = (C − 0,5) / 4.

В программе с номерами r и c от нуля:
  широта центра = 89,875 − r / 4;
  восточная долгота центра = 0,125 + c / 4.

Как выбрать ячейку по координатам точки
Пусть φ — широта в градусах, λ — восточная долгота в градусах.
Приведите λ к промежутку [0; 360), затем возьмите:
  r = floor((90 − φ) × 4), c = floor(λ × 4).
Здесь floor означает округление вниз. Для Южного полюса возьмите r = 719.
Эта договорённость выбирает южную и восточную ячейку, если точка лежит
точно на границе ячеек. В таблице используйте L = r + 1, C = c + 1.

Соседи для заливки
Порог сравнивают с исходной высотой z в метрах: ячейка допустима, если z < h.
Соседи имеют общую сторону: сверху, снизу, слева и справа.
Левый сосед столбца 1 — столбец 1440 той же строки; правый сосед
столбца 1440 — столбец 1. Верхняя и нижняя границы не соединяются.
Если стартовая ячейка не ниже уровня h, доступной из неё воды нет.

Площадь
Пиксели разных широт имеют разные площади. Для этой задачи считайте
Марс сферой радиуса R = 3389,5 км. Площадь одной ячейки в строке L:
  A_L = R² × (π / 720) × (sin(φ_N × π / 180) − sin(φ_S × π / 180)),
где φ_N = 90 − (L − 1) / 4 и φ_S = 90 − L / 4 — северная и южная
границы строки в градусах. A_L получается в км².
Площадь заливки — сумма площадей только достигнутых стартовой водой
ячеек. Можно умножить A_L на число таких ячеек в каждой строке и сложить.
При выводе «млн км²» разделите итог на 1 000 000.

Первичные источники и формат оригинала
Описание карт и разрешений:
https://pds-geosciences.wustl.edu/missions/mgs/megdr.html
Данные:
https://pds-geosciences.wustl.edu/mgs/urn-nasa-pds-mgs_mola_topography_derived/meg004/megt90n000cb.img
Исходная метка:
https://pds-geosciences.wustl.edu/mgs/urn-nasa-pds-mgs_mola_topography_derived/meg004/megt90n000cb.lbl
Метка PDS4:
https://pds-geosciences.wustl.edu/mgs/urn-nasa-pds-mgs_mola_topography_derived/meg004/megt90n000cb.xml
IMG — 720 × 1440 целых чисел со знаком, 16 бит, старший байт первым
(big-endian), без заголовка. Сначала вся первая строка, затем вторая и т. д.
В numpy это dtype='>i2'; в JavaScript — DataView.getInt16(offset, false).
Не применяйте к этим высотам масштаб или вертикальное усиление модели.
Вертикальное усиление меняет только рисунок; расчёт использует метры из CSV.

Сетка 4 пикселя/градус предназначена для контрольной заливки. Для глобуса
сохраните MOLA 16 пикселей/градус, а для профиля небольшого кратера —
более подробную сетку. Замена разрешения меняет численный результат
заливки и не подходит для проверки опубликованного контроля.
