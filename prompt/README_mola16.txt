МАРС В РАЗРЕЗЕ. ГЛОБАЛЬНАЯ СЕТКА MOLA ДЛЯ ГЛОБУСА

megt90n000eb.img — официальный глобальный продукт MOLA MEGDR
с разрешением 16 пикселей на градус (0,0625° × 0,0625°).
Скачанный оригинал сохранён без изменения байтов.

Формат: 2880 строк × 5760 столбцов, числа со знаком int16,
big-endian (старший байт первым), без заголовка и пустых промежутков.
Размер: 33 177 600 байт. Высоты в метрах относительно ареоида.
Строки идут от северного полюса к южному, долготы — от 0° до 360°E.
Координаты планетоцентрические. Нулевую высоту не считать пропуском.
В продукте пропущенные наблюдения уже заменены интерполяцией.

Для строки r и столбца c с нумерацией от нуля:
  широта центра = 89,96875 − r / 16;
  восточная долгота центра = 0,03125 + c / 16.

В numpy: np.fromfile(path, dtype='>i2').reshape(2880, 5760).
В JavaScript: DataView.getInt16(2 * (r * 5760 + c), false).
Для вывода глобуса можно проредить сетку, чтобы он быстро вращался.
Подпишите разрешение отображения и используемое вертикальное усиление.
Измерения по исходной сетке сохраняйте в её физических метрах.

Эта сетка подходит для общего вида планеты. Для небольшого кратера
возьмите более подробную сетку, как указано в условии.
Для опубликованной проверки заливки используйте отдельную сетку
4 пикселя/градус из mola4_topography_m.csv, не эту сетку.
